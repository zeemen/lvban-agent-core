## 二、每件必须采到什么（采不到就不能建）

门禁与规格只认下面这几样。**不是「拍清楚一点」，是逐栏对得上。**

| 栏 | 用在哪 | 采法 | 采不到怎么办 |
|---|---|---|---|
| **定名** | `name`、must_cite | 展签正拍，拍全，不裁边 | 没有定名的件直接放弃，别凭器型自己起名 |
| **时代** | must_cite（规格 03 §5.1） | 展签上的朝代字样 | **展签上没有朝代，文案里一个年代字都不许写**——银盒（435）就是这么处理的 |
| **尺寸** | must_cite | 展签；展签常常没有 | 留空，别拿目测的「约 30 厘米」顶上 |
| **出土地点** | must_cite | 展签 | 留空。「XX 墓出土」这类话只能照抄，不能从墓主推年代 |
| **说明牌正文** | `explanation` 三档的唯一依据 | 单独拍一张，拍全，别只拍开头两行 | 只有展签没有说明牌的件 → 内容会薄到像青釉执壶（53）那样，可收但记进待核 |
| **一个可数或可指的细节** | `observation`（§4.3 必要条件 4 的问题链） | 现场找：几朵花、几只足、几条纹；拍一张局部 | 找不到可指的细节 → 这件撑不起问题链，**按 §4.3 应当放弃** |
| **器物多角度照** | 视觉识别测试（§4.3 必要条件 3、§11 门槛） | 见第四节 | 玻璃反光糊到认不出 → 这件只能走「问一句」，记进待核 |
| **在展确认** | §4.3 第一条必要条件 | 记当天日期 + 展厅 + 展柜编号或方位 | 当天不在柜里 → 不进名单，无论典藏库怎么标 |
| **同厅易混件** | 候选集约束下的区分度 | 记一句「这件旁边有 N 件长得像的」 | 同柜三件四王山水那种 → 优先换别的 |
| **藏品 id** | `k1Sources` 回指详情页 | 展签上的馆藏号，或回来按定名在典藏库检索 | 查不到 → 展签本身当 K1，见下 |

### 展签能不能当 K1，要内容负责人点头

典藏库查不到的件（3 展厅那 3 件大概率如此），唯一的官方来源就是展签本身。`k1Sources` 的 `url` 是选填，所以结构上写得进去：

```json
{ "title": "南京博物院历史馆 3 展厅展签：<定名>，<时代>，<出土地>（现场拍摄，照片 njm_3f_001_qian.jpg）",
  "publisher": "南京博物院", "fetchedAt": "<拍摄日>" }
```

**但这条我不替内容负责人定。** 展签是馆方的正式标注，可信；问题是第三方拿不到照片就核不了，与现在 7 件「给个 URL 谁都能点开」不是一个成色。要用，照片得跟锚点文件一起进仓库或归档到固定位置，`title` 里写上文件名。

## 三、分厅任务

### 3 展厅「郡国华章 汉家故里」——汉代 3 件，这一趟最硬的一块

典藏库对这个厅是零标注，所以**没有预选名单，只能到现场逐柜看**。

1. 整厅走一遍，先拍一张**展厅全景与平面导览图**，确定这个厅实际的展线与展柜数。
2. 逐柜拍展签。**优先挑说明牌正文写得长的**——正文决定 `explanation` 能不能写够，决定钩子与讲解的 Dice 相似度能不能压到 0.5 以下（门禁 `content/hook_echoes_explanation` 是错误级，超了就挡提交）。
3. 挑件时按这个顺序排：说明牌有正文 > 有可数细节 > 器型独特不易混 > 展签字段齐全。**凑满 3 件就够，不必多拍**，但候选记 5–6 件，回来有一两件信息太薄可以换。
4. **玉衣在这一厅一并有结论**：
   - 看到玉衣 → 拍展签，**照抄定名**（「金缕」还是「银缕」还是别的），这同时结掉规格 04 §12.2 的 Q2，也可能直接占掉一个汉代位。
   - 没看到 → 拍下整厅展线照片，记「2026-XX-XX 现场逐柜未见玉衣」。这是否定证据里最硬的一种，`njm_yuyi` 从此可以明确不建，而不是一直挂着。
5. 这个厅补上之后，`njm_jiangtun_hu` 的 `nextAction` 要从 `njm_linghua_tongjing` 改指 3 展厅的件，动线变成 2→3→4→5→6。这条已经记在那个锚点的待核里。

### 4 展厅「六朝迭兴 隋唐华彩」——六朝 3 件

这个厅有标注的 4 件里 3 件是唐，所以**六朝那 3 件要在现场从展线上找**。

1. 认准朝代字样：**吴、东晋、南朝（宋齐梁陈）才算六朝**，唐的不算（唐菱花鸳鸯铜镜 163 已经占了工艺/技术位）。
2. 竹林七贤砖画就在这个厅，顺手确认它当天在不在、展签写的定名与出土地（典藏库写「江苏南京西善桥宫山大墓」，锚点与语料写「西善桥宫山南朝墓」，`njm_zhulin_qixian` 的待核里第 5 条要的就是这个表述统一）。
3. 砖画同墓或同类的其他件若在展，优先——与已建锚点同一条叙事，`nextAction` 串得顺。但**不要凭「应该是同一个墓的」自己认亲**，照展签写。

### 21 展厅 历代绘画馆——书画 2 件

这是唯一要跨馆的一站（历史馆 + 艺术馆 = 2 个馆，仍满足 §4.3 的 ≤3）。

1. 先确认**这两件当天在不在墙上**，它们是全池最值得要的：
   - **郑簠 孔子《蟪蛄吟》句（5059）**——写的正是孔子，和夫子庙那条科举/孔子叙事天然接得上。
   - **唐寅 李端端落籍图（2461）**——人物画，在一堆山水里 VLM 最好认。
2. 不在墙上就从**当天实际挂着的**里面挑 2 件，顺序：人物画或书法 > 花鸟 > 山水。**明确避开四王一路（王时敏、王鉴、王翚、王原祁）的山水**——候选池第四节的结论是这一类在候选集约束下区分度最低，用它们凑数会把 §11 的 80% 门槛压在最难的一类上。
3. **书画多问一栏：展期。** §4.3 要的是「常设展陈、长期在展」，书画轮换比器物频繁得多。展签或展厅告示上若写了展期，拍下来；没写就记「展期未标」，这件的待核里要留着。
4. 书画展签常常没有尺寸，也常常没有说明牌正文——**正文缺的件不要选**，没有正文就写不出三档讲解。

### 顺路要核的三件事（7 件已建锚点都在历史馆）

1. **7 件逐件在柜确认**：108、117、53（6 展厅），435、88（5 展厅），163（4 展厅），440（2 展厅）。当天不在柜里的，锚点要降级或替换。
2. **「正在展出」到底是什么意思**：详情页标这个的件，现场是不是真的在。这是推荐方案待核第 1 条——南博没公布这个字段多久更新一次，现在只能支持「官方称正在展出」，支持不了 §4.3 的「长期在展」。能问到工作人员更好。
3. **休息点**：§4.3 要求单条精选路线 2–3 小时走完、中途有一次休息点。记一下 2/3/4/5/6 展厅这条线上哪儿有座位或水吧。

## 四、识别测试怎么拍（§11 的 80% 门槛）

规格 02 §4.3 的原话是「在玻璃反光与人流遮挡下实测」，所以**样本必须带上这两样，不是拍几张标准照**。

每件至少 5 张：

```
① 正面标准照（人少时）
② 斜 45°（玻璃反光最明显的角度）
③ 局部细节（第二节里那个可数的细节）
④ 有人流遮挡时的一张（半挡住）
⑤ 远一点、带相邻展柜的一张（候选集里易混件同时在画面里）
```

馆内摄影规定以现场告示为准。**若禁用闪光，反光样本就只能靠角度去造**，照片里记一句当时的光照条件。

回来怎么算：把每件的候选集设成该展厅在册的件，逐张过 `decideVisionAnchor`，统计 top-1 命中。**这是代理指标，不是线上那个指标**——线上命中率的定义是 `1 − 用户纠正率`（滚动 200 次，02 §4.3），现场没有真实用户纠正，只能用 top-1 近似，结论里要写明这一点。

18 件 × 5 张 ≈ 90 张能看出大致水位。**这个量是我拍的，规格里没有规定样本量**，内容负责人觉得不够可以加。
