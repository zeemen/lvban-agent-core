## 四个必须守住的硬约束

这四条在规格里是红线，不是建议；每一条都有对应的执行点而不是靠调用方自觉。

1. **系统推断不进长期记忆。** `system_inferred` 来源永远停在瞬时层，要么被用户亲口说的坐实，要么在行后回顾里被确认。执行点：01 §3 写入网关。
2. **没有 open 的 Journey，就没有采集。** 不做全天候或后台持续追踪。执行点：02 §1 状态机 + 01 §3.1 网关校验。
3. **室内不伪造精确位置。** 只记用户确认过的展区与展品。执行点：02 §4。
4. **商户不进讲解。** Explanation Planner 的输入契约里结构上就没有商户字段。执行点：03 §3.1 + 04 §8。

## 规格之后

M2（引擎打通）才是第一行产品代码：Context Engine + Memory + Planner 端到端跑通，先不做小程序界面，用命令行或 HTTP 就能和 agent 对话，在内部把 H1/H4 测出来。小程序是 M3。

技术栈、仓库结构与 M2 的工程计划尚未决定，不在本批规格范围内。
