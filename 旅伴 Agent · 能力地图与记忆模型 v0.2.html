旅伴 Agent（暂定名）· 能力地图与记忆模型 · v0.2 · 2026-10-25 · 已确定首发场景、受众与模式

从"导"到"伴"一个随身的、有记忆的、会主动的旅行 agent

导游的工作在景点门口开始、在景点门口结束。伴的工作从"你想去哪"开始，到"下次我们去哪"才告一段落——而连接这条线的，是记忆。

核心命题

产品的差异不在"会讲解"，而在"越来越懂你"。讲解是能力，懂你是关系；前者可以被任何接入大模型的地图或 OTA 复制，后者只有持续陪伴才能积累。

导游式产品

以景点为中心，信息单向分发；每次打开都是陌生人；价值在行中、随行程结束而归零。

伴游式 agent

以人为中心，记忆持续累积；每次打开都接着上次；价值跨越行前、行中、行后，随次数递增。

首发场景与受众

受众定为亲子研学家庭，场景定为一室内一室外：南京博物院与夫子庙。两个 demo 的差异足够大，正好把定位、讲解触发、动线三件事各验证一遍。模式为纯线上轻资产——不布设备、不驻场，内容是唯一的资产。

为什么是亲子研学家庭

研学自带任务感，孩子是记忆最好的载体，家长是明确的付费方；而且"孩子一年年长大"本身就是记忆层最天然的时间轴——这是别的客群给不了的粘性。夫子庙的科举文化、博物院的历史脉络，也与现有初中语文、道法知识库天然衔接。

轻资产意味着什么

室内不能依赖自建信标，定位要靠手机本身：摄像头识别展品、楼层平面图、用户一句确认。内容库、研学任务库和记忆模型是全部家当，demo 阶段要把这三样做深，而不是把场景做多。

南京博物院（室内）夫子庙（室外）

研学任务是贯穿三段的第四条线

行前和孩子一起领一个"问题"（而不是一份清单），行中围绕问题触发讲解与采集，行后把问题的答案、走过的足迹和孩子说过的话织成一份研学记录。它不是独立功能，而是让"伴"有目的性的那根线。

能力地图

三个阶段各有自己的能力簇，但都站在同一条"记忆之河"上：上游写入、下游读取，河越深，每一段的服务越准。

行中一列加粗描边，因为它是最难做、也最像"伴"的部分；行前和行后分别是记忆的来源与去处。

记忆模型

记忆分四层，稳定度递减、时效性递增。设计的关键不在存什么，而在"什么能往上升"：瞬时的碎片经过旅程，被蒸馏成偏好；偏好被多次验证，才沉入身份。

蒸馏规则（草案）

瞬时 → 旅程用户明确表达的状态和意愿（"走不动了""这个好有意思"）即时写入；系统推断的只作为本次参考，不写入。
旅程 → 偏好行后一次性蒸馏：同类信号在本次出现≥2次，或用户在行后回顾中确认，才升为偏好；首次出现只记"提过一次"。
偏好 → 身份跨≥3次旅程稳定成立，且与同行结构无关，才沉入身份层；身份层每一条都应可被用户看到并一键删除。
轨迹 → 足迹原始定位点只在旅程层保留，行程结束后 7 天内压缩；长期沉淀的是"语义足迹"——到过的展厅 / 街区节点序列、停留时长、在哪里问了什么、在哪里被打动。足迹是孩子研学档案的骨架，也是下次规划的起点。
不写入健康状况、财务、敏感身份属性，以及任何用户没说、是系统猜的"画像"。孩子的所有数据由家长账户统一掌控，可整体导出、可一键删除——伴的前提是不被窥视。

粘性从哪里来

一个简单的飞轮。每一环都对应能力地图里的一簇能力，哪一环断了，粘性就会在那里漏掉。

环节用户感受到的系统在做的对应能力
第一次用比攻略 App 更像在和一个人商量意图理解、协同规划，先建立身份层行前
路上它在场，而且不烦人主动性引擎 + 动态调度，持续写入旅程层行中
回来后收到一篇像自己写的游记旅程沉淀，并把旅程蒸馏为偏好行后
第二次用"它记得我"——这是切换成本读取偏好层，规划起点已不是零行前（记忆读取）
第 N 次它开始先我一步提议身份层成熟，关系延续能力启动行后 → 行前

立项前要定的事

  1. 名字"伴游"不用。先在"旅伴 / 游伴 / 人格化角色名"三条路里选一条，角色名方向最利于建立"它是谁"的认知。
  2. 载体行中陪伴依赖后台定位、持续语音与主动推送，小程序限制较多。建议：小程序做行前规划与获客（游记回流入口），App 承担行中主体验。
  3. 室内定位方案轻资产下不能布信标，博物院只能靠手机：拍展品 / 展牌做视觉识别，配合展厅级确认和平面图。demo 第一件事是在玻璃反光与人流遮挡下实测识别命中率，低于八成就要把"拍一下"改成"问一句"为主。
  4. 家庭冷启动第一次用时身份层是空的。靠一段和孩子的自然对话（而不是家长填表）在 3 分钟内填出年级、一个兴趣入口、家长的节奏偏好三项，其余留给旅程去发现。
  5. 未成年人合规14 岁以下儿童的位置与行为数据，需监护人单独同意并适用单独的处理规则（《个人信息保护法》第 31 条、《儿童个人信息网络保护规定》）。定位采集的告知、足迹的导出与删除、家长账户的掌控权，要在 demo 阶段定下结构，上线前做一次合规评估。
  6. 内容资产两馆的讲解库、按年级分层的研学任务库、问题链，是轻资产模式下唯一能复用和定价的东西。demo 阶段的内容深度，决定了后面能不能横向扩到第三个馆。
